# Temperature Converter — TempSwap

A sleek, real-time temperature converter built with pure HTML, CSS, and JavaScript. Convert between Celsius, Fahrenheit, and Kelvin instantly with a modern dark-themed UI.

## Features

- **Real-Time Conversion** — Results update as you type, no button needed
- **Three Units** — Celsius (°C), Fahrenheit (°F), and Kelvin (K)
- **Swap Function** — One-click swap to reverse the conversion
- **Formula Display** — Shows the exact formula used for each conversion
- **Reference Table** — Common temperature benchmarks for quick lookup
- **All 6 Formulas** — Visual cards showing every conversion formula
- **Responsive Design** — Works on mobile, tablet, and desktop
- **CSS Animations** — Smooth transitions, hover effects, and scroll animations
- **Dark Theme** — Modern dark UI with warm gradient accents
- **Semantic HTML** — Clean, accessible markup
- **No Frameworks** — Built with vanilla HTML, CSS, and JavaScript only

## Tech Stack

| Technology | Purpose |
