# Personal Portfolio Website

A modern, responsive personal portfolio website built with pure HTML, CSS, and JavaScript. Features a dark theme with gradient accents, smooth animations, and clean design.

## Features

- **Responsive Design** — Fully responsive across all devices (mobile, tablet, desktop)
- **Dark Theme** — Professional dark color scheme with gradient accents
- **Typing Animation** — Dynamic typing effect in the hero section
- **Scroll Animations** — Fade-in effects on scroll using Intersection Observer
- **Skill Progress Bars** — Animated skill level indicators
- **Counter Animation** — Number counting animation for stats
- **Smooth Scrolling** — Seamless section navigation
- **Mobile Menu** — Hamburger menu with slide-in sidebar
- **Sticky Header** — Header becomes opaque on scroll
- **Contact Form** — Functional contact form with validation
- **Active Nav Highlight** — Navigation links highlight based on scroll position

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic structure & content |
| CSS3 | Styling, animations, responsive design |
| JavaScript | Interactivity & DOM manipulation |

## Sections

1. **Hero** — Introduction with typing effect and code window visual
2. **About** — Personal bio with animated stats
3. **Skills** — Technology cards with progress bars
4. **Projects** — Project showcase with links
5. **Contact** — Contact info and message form
6. **Footer** — Quick links and social media

## How to Run

1. Clone the repository
2. Open `index.html` in any modern browser
3. No build tools or dependencies required
