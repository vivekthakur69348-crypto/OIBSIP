# Task 1 — Landing Page

## Oasis Infobyte Web Development Internship (Level 1)

### Project: FocusFlow — Productivity App Landing Page

A fully responsive landing page for **FocusFlow**, a fictional productivity application. Built with **pure HTML5 and CSS3** — no frameworks or libraries used.

---

### Features Implemented

- **Header with Navigation** — Logo + 5 navigation links (Features, About, Testimonials, Pricing, Contact) with a sticky header effect
- **Hero Section** — Headline, subtitle text, two CTA buttons, and a CSS-only app mockup illustration with float animation
- **Features Section** — 4 feature cards with icons, hover effects, and descriptions
- **About Section** — Stats grid (50K+ users, 1M+ tasks, 99.9% uptime, 4.9 rating) with descriptive content
- **Testimonials Section** — 3 user testimonial cards with star ratings and author details
- **Pricing Section** — 3-tier pricing cards (Free, Pro, Enterprise) with a "Most Popular" badge
- **Contact/CTA Section** — Email signup form with gradient background
- **Footer** — 4-column layout with brand info, product links, company links, and social media links + copyright notice
- **Fully Responsive** — Mobile-first responsive design with breakpoints at 480px, 768px, and 992px
- **Mobile Navigation** — Hamburger menu with slide-in sidebar for mobile devices
- **CSS Animations** — Fade-in on scroll, floating mockup, hover transitions on cards/buttons, underline animation on nav links
- **Semantic HTML** — Proper use of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` tags
- **No Frameworks** — 100% pure HTML and CSS (vanilla JS only for mobile menu toggle and scroll animations)

---

### Tech Stack

| Technology | Purpose |
